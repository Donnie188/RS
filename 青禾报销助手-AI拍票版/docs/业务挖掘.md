# 业务挖掘 · 青禾报销助手 AI 拍票版

## 一、业务背景

企业员工报销是高频但低效的行政流程。传统报销模式下，员工需要手填金额、翻制度想科目、贴发票跑审批，财务每月要花大量时间核对票据真伪和合规性。

核心痛点：
1. **手填易错**：员工手工录入金额和科目，约 20% 单据被财务退回
2. **科目难选**：不知道住宿费算"差旅费-住宿"还是"业务招待"，靠问同事
3. **票据合规靠人工**：财务一张张验发票真伪、核对抬头税号，效率低
4. **审批流转慢**：纸质单据跑部门主管、跑财务，平均周期 5–7 天

## 二、目标用户

| 角色 | 痛点 | 诉求 |
| --- | --- | --- |
| 普通员工 | 报销填单半小时，退单来回跑 | 拍一张票自动填好，一键提交 |
| 部门主管 | 每天审批十几张单，不知道合不合规 | 系统预校验，只看异常单 |
| 财务专员 | 月底加班验票、对账 | AI 自动识别发票、预匹配科目 |
| 行政总监 | 报销制度落地靠人盯 | 制度口径自动校验，违规自动拦截 |

## 三、核心业务机会

- **AI 拍票识别**：拍一张发票，自动提取金额、商家、税号、日期，省去手填
- **科目智能推荐**：根据商家和金额自动推荐报销科目，准确率 85%+
- **合规预检**：招待费超阈值、专票金额过小等风险自动提示
- **审批流线上化**：提交后自动流转主管 → 财务，进度实时可查

## 四、商业模式

- **To B SaaS**：按企业员工数收年费（20 元/人/月）
- **增值服务**：发票验真 API 调用、财务报表自动生成

## 五、项目范围（一期）

- 员工端：拍票识别、自动填单、审批进度查询
- 主管端：审批待办、通过/驳回
- 财务端：复核、标记打款
- AI 能力：发票 OCR、科目推荐、合规预检
