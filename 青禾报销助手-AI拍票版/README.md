# 青禾报销助手 · AI 拍票版

微信原生小程序。解决一个具体问题：**员工报销时不用手填金额、不用想科目，拍一张发票，AI 自动识别并填好单。**

## 与常规版本的差异

本版本的切入点是 **"拍票 → 自动填单 → 审批流跟踪"**，而不是"制度问答查询"。核心 AI 能力落在**发票识别 + 科目推荐 + 合规预检**上。

| 维度 | 本版本（AI 拍票版） |
| --- | --- |
| 核心流程 | 拍票识别 → 自动填单 → 主管审批 → 财务复核 → 打款 |
| AI 介入点 | 发票 OCR、金额提取、报销科目推荐、合规风险预检 |
| 角色 | 李小禾（员工）/ 王建国（主管）/ 陈雅琴（财务） |
| 主题色 | 深蓝 #2563EB |
| TabBar | 首页 / 拍票 / 审批 / 账单 / 我的 |

## 三种角色与权限

| 角色 | 是谁 | 能做什么 |
| --- | --- | --- |
| 员工 | 李小禾 | 拍票报销、查看本人单据进度、撤回草稿 |
| 主管 | 王建国 | 审批下属提交的报销单（通过 / 驳回） |
| 财务 | 陈雅琴 | 复核主管通过的单据、标记打款 |

权限边界：员工只能看到自己的单据；主管看到本部门待办；财务看到全部已过主管的单据。

## 功能

**拍票报销（核心）**
- 模拟 OCR：识别发票类型、商家、金额、税号、日期
- 自动推荐报销科目（差旅费-交通 / 住宿 / 业务招待 / 办公费）
- 合规预检：招待费超阈值、专票金额过小等风险提示

**审批流**
- 状态机：草稿 → 已提交 → 主管审批 → 财务复核 → 已打款 / 已驳回
- 每一步留痕时间轴，谁在什么时间做了什么操作
- 主管通过后自动流转到财务；财务复核通过即标记打款

**账单查询**
- 按状态筛选（全部 / 审批中 / 已打款 / 已驳回）
- 点击单据查看完整流转时间轴

## 目录结构

```
.
├── app.js / app.json / app.wxss     # 小程序入口、页面注册、全局样式
├── project.config.json              # 开发者工具配置（测试号）
├── sitemap.json
├── pages/
│   ├── index/                       # 首页：进度概览 + 三个入口
│   ├── capture/                     # 拍票：OCR 识别 + 自动填单
│   ├── approval/                    # 审批中心：按角色显示待办
│   ├── bills/                       # 我的账单：状态筛选 + 时间轴
│   └── me/                          # 我的：身份信息 + 角色切换
└── utils/
    ├── dict.js                      # 角色 / 状态 / 科目字典
    ├── seed.js                      # 演示发票池与历史单据
    ├── ocr.js                       # 模拟发票 OCR 识别
    └── store.js                     # 数据层 + 本地权限规则
```

## 运行

1. 打开**微信开发者工具** → 导入项目 → 选择本目录
2. AppID 选**测试号**（touristappid）
3. 编译即可运行

在「我的」页面可一键切换三种角色体验不同视角。

## 数据说明

当前为本地体验模式，所有数据存在本机 Storage 中。`utils/seed.js` 内置 4 张示例发票与 4 张历史单据，均为演示数据。接入真实环境时，把 `utils/ocr.js` 替换为微信 OCR 插件或云函数，把 `utils/store.js` 的方法体换成云端数据库调用即可，页面代码无需改动。
