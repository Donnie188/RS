# 项目简报 01：公司背景与业务现状

**智家速修**是一家智能家居/家电后市场服务企业，主营空调、热水器、智能门锁等品类的安装、维修与保养，
服务模式为“总部接单 → 区域门店派单 → 工程师上门 → 回款与售后报销”。

## 关键经营数据（2026 财年，访谈与简报交叉核实）
| 指标 | 数值 |
|---|---|
| 员工总数 | 320 人（一线工程师 240 人） |
| 门店 | 华东 4 家，总部杭州 |
| 月均工单 | 12,000 单 |
| 月均报销单 | 900+ 张 |
| 工单超时率 | 15% |
| 月均客诉 | 约 32 起 |
| 违规/可疑报销票据 | 12~18 张/月 |

## 业务链条
客户报修（电话/微信）→ 客服登记 → 店长派单 → 工程师上门维修 → 客户签字确认 → 工程师费用报销 → 财务审核打款。
