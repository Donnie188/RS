# 阶段 7 · 上线前检查清单（Go / No-Go）

> 适用系统：智家速修 AI 售后工单（报销助手智能体），技术栈 FastAPI + SQLite + SSE + Function Calling Agent。
> 共 5 个维度 × 5 项 = **25 项检查**，每项标注：**负责人角色 / 验证方法 / 通过标准**。
> 其中 8 项（标 ★）已在代码层面落地为可执行的验证手段，其余为上线前的操作类检查。

## 二、并发与限流（LLM 调用配额）

| # | 检查项 | 负责人角色 | 验证方法 | 通过标准 |

| 1 | ★ 单用户滑动窗口限流 | 后端工程师 | 1 分钟内连续发 61 次 `/api/chat`（评测器/压测脚本） | 第 61 次返回 `code=1003` HTTP 429 中文提示；其余全部正常 |

| 4 | SSE 长连接与 SQLite 并发 | 后端工程师 | 两个终端同时：A 连续流式问答，B 管理员上传/删除文档 | 双方均正常完成，无 `database is locked` 报错（WAL + busy_timeout 生效） |

## 三、异常兜底（LLM 超时 / 工具失败时用户看到什么）

| # | 检查项 | 负责人角色 | 验证方法 | 通过标准 |
|---|---|---|---|---|
| 1 | LLM 完全不可用时的降级 | 后端工程师 | 清空 `LLM_API_KEY`（或断网）后提问 | 用户看到检索原文拼接的制度答案 + 引用来源，页面无白屏、无裸异常栈 |
| 2 | 单轮 LLM 调用失败的流内提示 | 后端工程师 | 用错误 base_url 启动，提问 | SSE 流内出现 `error` 事件（code=4001 中文信息），随后 `done(degraded=true)` |
| 3 | 工具执行异常不中断会话 | QA 工程师 | 构造发票日期为非法格式（如 2026-13-99）走校验流程 | 得到"数据校验失败：日期不合法"的结构化 violation，Agent 正常作答，会话可继续 |
| 4 | Agent 循环兜底（步数耗尽） | QA 工程师 | 检查 `loop.py` 第 5 轮耗尽逻辑：强制 escalate_to_human 并给用户明确话术 | 用户看到"已转人工"，工具日志里有 5 轮完整记录，无死循环 |
| 5 | 用户侧错误全中文 + 错误码 | QA 工程师 | 触发空问题 / 超长问题 / 知识库为空 / 未登录四类请求 | 依次返回 1001/1002/3001/401，消息均为中文，无堆栈泄露 |

## Go / No-Go 判定

- **全部 25 项通过** → Go；
- **第一/四维度（数据安全、内容安全）任何一项不通过 → No-Go**（合规红线）；
- 其余维度允许带 1 项"低风险偏差 + 已有缓解措施"上线，限期整改。
