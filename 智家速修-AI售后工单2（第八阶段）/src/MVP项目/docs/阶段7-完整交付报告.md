## 二、逐项对照：提示词要求 → 实现位置 → 验证方法

### 提示词 2（架构选型）

| 要求 | 实现 | 验证 |
|---|---|---|
| FastAPI 异步，Python 3.11+ | `app/main.py`，SSE 用 StreamingResponse + 线程池 | `pip install -r requirements.txt` 后启动即可 |
| LLM 可替换供应商 | `app/config.py` 5 家预设（deepseek/moonshot/dashscope/zhipu/openai），`app/llm.py` 统一 OpenAI 兼容协议 | 只改 `.env` 的 `LLM_PROVIDER/LLM_API_KEY` |
| 知识库向量化检索 | `app/rag.py`：500 字切片 → Embedding（无 Key 自动降级本地哈希向量）+ BM25(jieba) → RRF(k=60) 融合 | 提问后回答带引用来源 |
| 四层架构 | 入口层 main.py / 服务层 rag+llm+auth+security / 智能体编排层 app/agent / 数据层 db.py | 目录即架构 |
| 四张核心表 + 报销扩展 | users / sessions / messages / kb_documents+kb_chunks / prompt_templates / validation_records / drafts / tool_calls | `docs/` 与 README 表结构说明 |
