# 设计方案 · 智家速修 AI 售后工单系统

## 一、系统架构

```
用户端小程序（报修/查询）
        ↓
   API 网关
        ↓
工单服务 ←→ AI 服务（意图识别/故障初诊/智能派单）
        ↓
工程师端小程序（接单/签到/维修记录）
        ↓
管理后台（监控/数据看板）
```

## 二、核心流程

### 现状流程（传统人工模式）

用户打 400 电话 → 客服手工记录 → 主管人工分诊 → 人工派单 → 工程师上门 → 维修完 → 客服电话回访

**痛点**：全流程人工，平均处理时长 4 小时，一次修复率 72%

### 数智化转型后流程

用户一键报修 → AI 意图识别建档 → AI 故障初诊 → 判断能否远程解决
  - 能远程 → 推送自助教程 → 闭环
  - 不能远程 → AI 智能派单 → 工程师上门 → 维修 → AI 满意度预测回访

**提升**：平均处理时长 1.5 小时，一次修复率 90%

## 三、AI 能力清单

| AI 能力 | 作用 | 技术方案 |
| --- | --- | --- |
| 意图识别 | 自动归类故障类型 | NLP 分类模型 |
| 故障初诊 | 给出 Top3 可能原因 | 知识库向量检索 |
| 智能派单 | 匹配最近最合适工程师 | 距离+技能+负载算法 |
| 满意度预测 | 预警低分工单 | 维修时长+沟通记录模型 |

## 四、技术栈

- 前端：微信原生小程序
- 后端：Node.js + MySQL
- AI：接入第三方大模型 API
- 部署：云服务器（阿里云/腾讯云）

## 五、权限设计

- 用户：只能看自己的工单
- 工程师：看分配给自己的工单
- 主管：看全部工单，可人工改派
- 管理员：全权限
