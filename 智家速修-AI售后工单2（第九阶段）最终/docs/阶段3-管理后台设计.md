# 阶段 3：管理后台设计（页面清单 + 接口清单）

> 对应课程提示词 5。管理后台为服务端渲染（Jinja2），风格类 SaaS。

## 一、页面清单（4+1 页）

| 页面 | 路由 | 角色 | 功能 |
|---|---|---|---|
| 登录页 | GET /login | 公开 | 账号密码登录，签发 JWT 到 HttpOnly Cookie |
| 员工聊天页 | GET /chat | 员工/管理员 | SSE 流式问答、工具卡片、草稿确认卡、引用来源 |
| 知识库管理 | GET /admin/kb | 管理员 | 上传 md/pdf→自动切片→向量化入库；列表/删除（确认点③） |
| 提示词模板 | GET /admin/prompts | 管理员 | 编辑系统提示词（存数据库即改即生效，不写死代码） |
| 对话审计 | GET /admin/audit | 管理员 | 按员工/时间筛选对话与工具调用，标记疑似违规 |

## 二、核心接口清单

| 接口 | 方法 | 角色 | 说明 |
|---|---|---|---|
| /login | POST | 公开 | 表单登录，303 + Set-Cookie |
| /api/chat | POST | 员工 | SSE 流式问答（session/delta/tool_call/tool_result/pending_draft/error/done） |
| /api/drafts/{id}/confirm | POST | 员工 | 确认卡确认 → 提交（终态动作不经模型） |
| /api/drafts/{id}/cancel | POST | 员工 | 取消待确认草稿 |
| /api/sessions/{sid}/toolcalls | GET | 员工本人/管理员 | 工具调用轨迹回放 |
| /admin/kb/upload | POST | 管理员 | 上传文档并入库 |
| /admin/kb/{id}/delete | POST | 管理员 | 删除文档及其切片向量 |
| /admin/prompts/save | POST | 管理员 | 保存提示词模板 |
| /admin/audit/flag | POST | 管理员 | 标记疑似违规问答 |

## 三、鉴权与约束

- JWT 存 HttpOnly Cookie，接口级依赖注入校验角色（`require_admin`）；
- 默认提示词模板按课程要求预置（"只根据制度条文回答，不确定时明确说'制度中未找到'，回答末尾附引用来源，不得编造报销标准"）；
- 所有管理操作全量留痕，审计页可见（含拦截记录 blocked=true）；
- 错误统一返回错误码 + 中文错误信息（详见 docs/阶段2-接口设计.md 的错误分层）。
